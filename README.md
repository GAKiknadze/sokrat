# sokrat: информационный стиль для нейросетей

Скилы и промпты, которые учат Claude Code и другие нейросети писать сильный текст: кратко, ясно, честно, с заботой о читателе. Основа — методика информационного стиля из книги Максима Ильяхова и Людмилы Сарычевой «Пиши, сокращай: Как создавать сильный текст» (2-е изд., 2017).

Здесь только изложение правил и приёмов своими словами с короткими примерами. Текста книги в репозитории нет. Книгу стоит прочитать целиком. Авторы опираются на «Слово живое и мёртвое» Норы Галь, «Живой как жизнь» Корнея Чуковского, «Догму» редакции «Ведомостей» и «Элементы стиля» Уильяма Странка — их тоже стоит прочитать.

## Что внутри

| Скил | Когда срабатывает |
|---|---|
| `infostyle` | Написать или отредактировать любой рабочий текст: письмо, объявление, статью, пост, отчёт, инструкцию, интерфейс |
| `infostyle-review` | Проверить готовый текст: найти воду и стоп-слова, объяснить, исправить |
| `infostyle-selling` | Реклама, описание продукта, «О компании», «О себе», портфолио |
| `infostyle-cover-letter` | Отклик на вакансию, сопроводительное письмо, ответы работодателю |

У скила `infostyle` есть справочники, которые агент читает по необходимости:

- `references/stop-words.md` — 8 групп стоп-слов со списками и заменами;
- `references/sentences.md` — информативность, синтаксис, запятые, однородные члены;
- `references/text-structure.md` — абзацы, цель и задачи, модули, вступление, заключение, заголовки;
- `references/explaining.md` — дидактика, конкретика и абстракции, факты, вкус и здравый смысл;
- `references/honesty.md` — давление «смягчите», неудобная правда, этика автора.

Для нейросетей без поддержки скилов:

- `portable/SYSTEM_PROMPT.md` — вся методика одной инструкцией (около 1500 слов);
- `portable/SHORT_PROMPT.md` — короткая версия до 1000 знаков для полей с ограничением длины.

## Установка

### Claude Code: как плагин

```
/plugin marketplace add GAKiknadze/sokrat
/plugin install infostyle@sokrat
```

Скилы срабатывают сами, когда вы просите написать или поправить текст. Вызвать вручную: `/infostyle:infostyle`, `/infostyle:infostyle-review`, `/infostyle:infostyle-selling`, `/infostyle:infostyle-cover-letter`.

### Codex: как плагин

```bash
codex plugin marketplace add GAKiknadze/sokrat
```

Затем в Codex откройте `/plugins` и установите `infostyle` из маркетплейса `sokrat`.

Скилы срабатывают сами по описанию задачи. Вызвать вручную: `$infostyle`, `$infostyle-review`, `$infostyle-selling`, `$infostyle-cover-letter` или выбрать в `/skills`.

### Claude Code, Codex, Gemini CLI, Copilot CLI: как личные скилы

Выберите один способ: плагин или личные скилы. Если поставить оба, агент увидит каждый скил дважды.

```bash
git clone https://github.com/GAKiknadze/sokrat.git
cd sokrat
bash install.sh
```

Скрипт создаёт симлинки в `~/.claude/skills/` (Claude Code) и `~/.agents/skills/` (общую папку, которую читают Codex, Gemini CLI и Copilot CLI). Дальше:

- перезапустите агента, чтобы он увидел скилы;
- вызывайте их без префикса: `/infostyle` в Claude Code, `$infostyle` в Codex;
- удаляйте командой `bash install.sh --uninstall`.

Чтобы подключить скилы только к одному проекту в Codex, скопируйте папки из `skills/` в `.agents/skills/` этого проекта.

### Gemini CLI: как расширение

```bash
gemini extensions install https://github.com/GAKiknadze/sokrat --auto-update
```

Флаг `--auto-update` включает автообновление. Расширение добавляет `portable/SYSTEM_PROMPT.md` в контекст каждого разговора. Личные скилы загружаются только под задачу с текстом и тратят меньше контекста.

### Другие нейросети

| Где | Что сделать |
|---|---|
| opencode и агенты с `AGENTS.md` | Скопировать `portable/SYSTEM_PROMPT.md` в `AGENTS.md` проекта |
| Cursor | Создать `.cursor/rules/infostyle.mdc` с текстом `portable/SYSTEM_PROMPT.md` |
| GitHub Copilot в редакторе | Скопировать `portable/SYSTEM_PROMPT.md` в `.github/copilot-instructions.md` |
| ChatGPT | «Настройки → Персонализация → Пользовательские инструкции»: вставить `portable/SHORT_PROMPT.md`. В GPTs и Projects — `portable/SYSTEM_PROMPT.md` |
| Claude.ai Projects | Вставить `portable/SYSTEM_PROMPT.md` в инструкции проекта |
| API любой модели | Передать `portable/SYSTEM_PROMPT.md` как системный промпт |

## Обновления

### Claude Code

Claude Code сам обновляет плагины из маркетплейса, если для него включено автообновление. Для `sokrat` оно по умолчанию выключено: так Claude Code поступает со всеми маркетплейсами, кроме официальных. Включить:

1. Запустите `/plugin` и перейдите на вкладку **Marketplaces**.
2. Выберите `sokrat`.
3. Выберите **Enable auto-update**.

Claude Code скачает новую версию после старта сессии, а загрузит её после `/reload-plugins` или в следующей сессии. Обновить сразу: `claude plugin update infostyle@sokrat`.

### Gemini CLI

Расширение обновляется само, если его поставили с флагом `--auto-update`:

```bash
gemini extensions install https://github.com/GAKiknadze/sokrat --auto-update
```

Если расширение уже стоит без флага, удалите его командой `gemini extensions uninstall infostyle` и поставьте заново.

### Codex

Обновите маркетплейс командой:

```bash
codex plugin marketplace upgrade sokrat
```

### Личные скилы

Скрипт `install.sh` ставит симлинки на папку репозитория, поэтому скилы обновляет `git pull` в этой папке. Чтобы обновлять их каждый день в 10:00, добавьте строку в `crontab -e`:

```
0 10 * * * git -C /путь/к/sokrat pull --ff-only --quiet
```

Замените `/путь/к/sokrat` на свою папку. Если компьютер в это время выключен, cron пропустит обновление до следующего дня.

## Как пользоваться

- «Напиши объявление жильцам: 29 сентября отключат горячую воду с 8 до 16, нужен доступ в квартиры».
- «Проверь этот текст для страницы „О компании“».
- «Сократи письмо, сделай понятнее».
- «Помоги написать отклик на вакансию, вот описание и моё резюме».

Скилы не выдумывают факты. Если тексту не хватает цифр, сроков или примеров, агент спросит о них или оставит пометку `[нужен факт: …]`.

## Выпуск новой версии

Агенты замечают обновление плагина по номеру версии. После правок в `skills/` поднимите версию во всех манифестах одной командой и закоммитьте изменения:

```bash
bash bump-version.sh patch   # правки текста скилов: 1.0.0 → 1.0.1
bash bump-version.sh minor   # новый скил или справочник: 1.0.0 → 1.1.0
bash bump-version.sh major   # переименование или удаление скилов: 1.0.0 → 2.0.0
```

Скрипт меняет версию в `.claude-plugin/plugin.json`, `.claude-plugin/marketplace.json`, `.codex-plugin/plugin.json` и `gemini-extension.json` и останавливается, если версии в них уже расходятся.
